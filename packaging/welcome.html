សូមស្វាគមន៍មកកាន់ Mathtype-kh

កម្មវិធី Mathtype-kh សម្រាប់ macOS ជំនាន់ 64-bit ដំណើរការជាមួយ LaTeX Kernel (300 DPI) និងការតភ្ជាប់ជាមួយ Microsoft Word យ៉ាងស៊ីជម្រៅ៖

⚡ លក្ខណៈពិសេសចម្បង៖
  • បញ្ចូលទៅ Word ដោយចុច ១ ដង (One-Click Auto Insert into Word) ឬចុច Enter
  • តម្រឹមកម្ពស់បន្ទាត់ស្វ័យប្រវត្តិ (Automatic Baseline Depth Alignment)
  • មុខងារ Toggle TeX (ស្រង់យករូបមន្តពី Word មកកែសម្រួលក្នុង MathType វិញ)
  • ទំហំអក្សរលំនាំដើម 12 pt ស៊ីគ្នានឹងទំហំស្តង់ដារក្នុង Microsoft Word
  • កំណត់ផ្លូវ LaTeX Path ក្នុងម៉ឺនុយ Help យ៉ាងងាយស្រួល
  • ទ្រទ្រង់គ្រប់ Mac (Universal Binary សម្រាប់ទាំង Apple Silicon M1/M2/M3/M4 និង Intel)

💡 ចំណាំ៖ ដើម្បីឱ្យការបង្កើតសមីការច្បាស់កម្រិត 300 DPI ដំណើរការ សូមប្រាកដថាកុំព្យូទ័ររបស់អ្នកមានដំឡើង MacTeX ឬ BasicTeX (ឧ. តាមរយៈ brew install --cask mactex-no-gui)។
